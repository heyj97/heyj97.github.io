개인정보처리방침

시행일: 2026년 11월 17일

newgenlab은 한 사람이 자기 PC에서 실행하는 개인용 도구입니다. 서버를 운영하지 않으며, 이 도구를 만든 사람과 쓰는 사람이 같습니다.

읽는 정보

사용자가 Google 계정으로 로그인해 유튜브 채널을 연결하면, 다음 정보를 YouTube API로 읽습니다.

  • 채널 이름, 구독자 수, 누적 조회수, 영상 수
  • 채널에 올린 영상의 제목, 게시일, 조회수, 좋아요 수, 댓글 수
  • 기간별 조회수와 예상 수익

요청하는 권한은 모두 읽기 전용입니다. 영상을 올리거나 지우거나 채널 설정을 바꾸지 않습니다.

쓰는 목적

읽은 정보는 사용자 자신에게 채널 현황을 보여 주는 데에만 씁니다. 광고, 분석, 판매에 쓰지 않습니다.

보관하는 곳

읽은 정보와 Google 로그인으로 받은 인증 정보는 도구가 실행되는 사용자의 PC에만 저장합니다. 외부 서버로 보내거나 다른 사람과 공유하지 않습니다.

제3자 제공

어떤 정보도 제3자에게 제공하지 않습니다.

연결 해제와 삭제

  • 도구의 설정 화면에서 채널 연결을 해제하면 그 채널의 인증 정보가 PC에서 지워집니다.
  • Google 계정의 액세스 권한 관리에서 이 도구의 접근을 언제든지 취소할 수 있습니다.

YouTube API 서비스

이 도구는 YouTube API 서비스를 사용합니다. 사용자는 YouTube 서비스 약관과 Google 개인정보처리방침의 적용을 받습니다.
